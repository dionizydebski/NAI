# NAI

5. K-mean

Aplikacja stworzona w Pythonie, realizująca algorytm grupowania k-means. Program umożliwia wczytanie zbioru danych oraz przeprowadzenie klasteryzacji na podstawie wybranej liczby grup. Użytkownik może śledzić przebieg działania algorytmu za pomocą interfejsu tekstowego, który prezentuje kolejne etapy aktualizacji centroidów i przypisywania punktów do klastrów. Projekt skupia się na zrozumieniu i implementacji logiki algorytmu
